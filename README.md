#Sistema de Agendamento de Consultas - Especificaçao de Requisitos

##1. Visao Geral
Este documento especifica os requisitos funcionais e nao funcionais do modulo de agendamento.

##2. Requisitos Funcionais (RF) 
-[] RF1: O paciente deve conseguir visualizar os horários disponíveis de cada médico.
-[] RF2: o sistema deve permitir o agendamentode consultas com confirmações via whatsApp e e-mail.
-[] RF3: o médicp deve visualizar sua agenda diária e semanal.

##3. Requisitos não funcionais (RNF)
-RNF01 (Desempenho):  o tempo de resposta para busca de horários não deve exceder 2 segundos.
-RNF02 (Segurança): Dados sensíveis de saúde devem estar em conformidade com a LGPD.
